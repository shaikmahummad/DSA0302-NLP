## Important academic integrity / evidence note
This is a reproducible synthetic teaching prototype. It does NOT claim that 1,200 real citizen reports, 300 real call transcripts, 40 human-written bulletins, 5,000 professionally translated sentence pairs, or independent human annotations were collected. The assignment explicitly requires documented data and measurements. Use the generated examples to test the code, then replace them with approved anonymized data and human annotations before submitting any claimed human agreement, BLEU, human rating, or deployment accuracy.

The report labels prototype evidence and required human evaluation separately. Do not invent annotator agreement or native-speaker translation scores.
