# DSA03 NLP Assignment 4 package

## Run
```bash
python run_assignment.py
python -m unittest discover -s tests -v
```

The demo uses a small synthetic circular collection and illustrative pension rules. It is not legal advice or an authoritative eligibility engine.

## Important evidence limitation
The assignment requires 300 circulars/60,000 tokens, 200 real enquiries, 40 FOPC rules, 600 manually sense-labelled occurrences, a 50-rule semantic grammar, and human relevance judgements. This package demonstrates the pipeline but does not fabricate those real resources or independent annotator agreement. Replace the synthetic corpus with approved circulars and conduct the required annotation/evaluation before reporting empirical claims.
